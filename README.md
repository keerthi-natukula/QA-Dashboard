# QA Dashboard - Power BI

## Project Overview
This Power BI dashboard provides a comprehensive overview of QA audit performance using sample audit data. It helps monitor quality metrics, identify trends, and evaluate agent performance.

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX
## Skills Demonstrated

- Power BI Dashboard Design
- Data Visualization
- DAX Measures
- Power Query
- KPI Analysis
- Data Modeling
- Interactive Reporting

## Dashboard Features
- Total Audits
- QC Percentage
- Rejection Analysis
- Open vs Closed Issues
- Error Category Breakdown
- Agent Performance
- Weekly and Monthly Trends

## Key Insights
- Track audit quality over time
- Identify high rejection categories
- Monitor individual agent performance
- Compare QA metrics across different periods
