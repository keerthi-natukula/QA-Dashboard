# QA Dashboard

## Project Overview

This Power BI dashboard was created using sample QA audit data to monitor audit performance and quality metrics.

## Tools Used

- Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Features

- Total Audits
- QC Percentage
- Rejection Analysis
- Agent Performance
- Error Category Analysis
- Open vs Closed Issues
